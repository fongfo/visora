## 混音实测与第 8 节差异

使用固定 1.0 振幅控制信号，1–3 秒为配音窗口；BGM 基础音量为 0.4。稳态测量窗口为 1.5–2.8 秒，恢复采用 20ms RMS 窗口、10ms 步进，恢复阈值定义为相对原 BGM 电平不低于 -1dB。

| 参数 | 稳态压低 | 恢复时间 | 数值验收 |
| --- | --- | --- | --- |
| 原文 threshold=0.12, ratio=4, attack=50, release=300 | -13.812dB | 310ms | 未通过 |
| 校准 threshold=0.1, ratio=4, knee=1, attack=50, release=300, detection=peak | -15.000dB | 150ms | 通过 |

校准方案从已知配音时间轴生成固定振幅的侧链包络，避免实际人声响度变化改变压低幅度。该包络不是可听人声，不会加入最终混音；配音文件内的短暂停顿仍视为配音窗口。原文直接以人声作为侧链的版本保留为 `speech-spec-mix.wav`，方便 A/B 试听。

FFmpeg 实测存在侧链 EOF/帧对齐导致 BGM 尾部截短的问题。实现通过两输入补零、统一 1024 样本块、单滤镜线程和明确输出时长解决，并逐样本校验输出长度。`amix` 显式关闭自动归一化，避免双轨默认衰减；最终混音峰值约 0.711，无 PCM 削波。

这里通过的是数值与结构检查。音乐恢复是否自然、配音音色是否适合商业广告，仍需人工试听，不能用这份报告替代。

## 执行解释

1. 3.0 / 4.0 / 4.5 / 3.5 秒视为四个场景的基础时间轴预算。只对前 3 个源片段各补 0.3 秒转场，避免末段多补一次。实际 TTS 时长测量后，预算向上取整到 30fps 帧边界。
2. 0.15 秒配音起始偏移 + 0.3 秒句尾留白计入时长预算，并强制检查实际留白处于 200–400ms。短配音镜头会缩短至不超过 400ms 留白；无配音镜头保持基础配额不变。这是为满足 DoD 对短配音未明确算法的实现补充。
3. 超预算超过 0.4 秒或总时长超过 16 秒抛出 RewriteRequired(action=condense)；当短配音全部安排后无法达到 14 秒下限，则抛出 action=expand，不能用超长静音伪造合格时长。本地不调用 LLM 自动改写；上层应根据 action 改写后重新生成 TTS，并限制改写次数。
4. 5 秒源片段并不总能同时支持 0.5 秒避开伪影和目标镜头长度；不足时明确拒绝，不自动截掉配音或冻结画面。
5. SUCCESS / FAILED / CANCELLED 为互斥 Job 终态，不按文档箭头串成成功后失败再取消。OUTDATED 是素材有效性标记，与 Scene 处理状态分开。
6. 幂等指纹使用规范化 JSON，包含场景、Provider、关键帧、动作提示、参数以及版本。单进程锁保证并发重复提交共用任务；显式重抽增加版本，产生新任务。

- 内存状态不跨进程或重启持久化，不能替代 Redis 原子去重与数据库事务。

- 取消本地等待不会假称取消上游收费任务；真实 Provider 需要自己的取消与账单语义。
- 字幕为本地句级样例，不包含商业商品保真、真实模型输出、真实 API 成本或服务商响应时长验收。
- 单镜头重抽后仍需整体 FFmpeg 合成，最终可下载时间应计入该渲染耗时。
